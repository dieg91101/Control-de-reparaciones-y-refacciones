# Sistema de Control de Reparaciones

## Descripción

Sistema web para administrar talleres de reparación utilizando un flujo Kanban.

## Características

- Gestion de clientes
- Gestión de inventario
- Control de refacciones
-Órdenes de reparación
- Historial
- Dashboard
- Búsqueda
- Cálculo automático de costos

## Tecnologías

React

Django

Django REST Framework

SQLite
